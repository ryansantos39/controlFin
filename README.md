# Controle Financeiro

App pessoal de controle financeiro: lançamentos com parcelas e fatura de cartão, fixos mensais, orçamento por categoria, resumo anual e painel.

- Tela: este `index.html` (GitHub Pages).
- Dados e login: Supabase (projeto `controle-financeiro`, região São Paulo). Cada usuário só acessa os próprios dados (Row Level Security).
- A chave no código é a chave pública (publishable) do Supabase, feita para ficar no navegador.
